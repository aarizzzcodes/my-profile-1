# ✦ Aariz — Developer Portfolio ✦

Live at : https://aarizzzcodes.github.io/my-profile-1/

A modern, fast, and interactive personal developer portfolio built with pure HTML5, CSS3, and JavaScript.

---

## 🌟 Features

- **Interactive Constellation Canvas**: Background particles that float and react dynamically to mouse movements.
- **Magnetic Trailing Cursor**: Glowing dual-ring cursor with hover states over clickable cards.
- **3D Perspective Tilt**: Interactive project and skill cards that tilt in 3D on hover.
- **Terminal Playground**: Interactive code window with switchable tabs (`aariz.ts` & `specs.json`).
- **Project Filter**: Real-time category filtering (Web, IoT & Hardware, Systems & Python).
- **Toast Feedback**: Copy email to clipboard and contact form notifications with zero page reloads.
